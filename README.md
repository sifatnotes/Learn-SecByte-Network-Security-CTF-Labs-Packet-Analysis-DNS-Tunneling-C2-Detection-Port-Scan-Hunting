## Learning Path

1. **Start with security fundamentals:** Explore email protection and mailbox threat hunting.
2. **Investigate network evidence:** Practice analyzing packet-related information and lateral movement signals.
3. **Study suspicious communications:** Explore DNS activity, command-and-control indicators, and beaconing concepts.
4. **Recognize authentication attacks:** Compare password spraying and brute-force activity.
5. **Develop reconnaissance detection skills:** Finish with network scan and port scan investigations.

Adapt the order to the requirements and learning objectives provided by each lab.

## How to Use the Labs

1. Open the official lab using its direct link.
